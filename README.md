# ICMS ProMax (LPDSI Limay 1)

A web-based plant management system built for tracking, scheduling, and monitoring Corrective and Preventive Maintenance operations.

---

## 📌 Key Features

* **Today's Focus Dashboard**: Real-time breakdown of current shift statuses including Scheduled, Break-In, In-Progress, and Completed tasks.
* **Work Order Management**: Comprehensive tracking of corrective work orders, priority levels, equipment tags, target dates, and assigned manpower.
* **Break-In Hub**: Quick logging and capturing of unplanned or emergency break-in jobs without requiring an initial formal WO number.
* **Notification Center**: Persistent, real-time alert system powered by Supabase to track overdue PMs, low stock inventory, and task assignments.
* **Master Data Hub**: Centralized registry managing spare parts inventory (Item Master) and plant system structures.
* **Shift Reports & Logs**: Rapid generation of CM Shift Reports and supervisor daily accomplishment logs.
